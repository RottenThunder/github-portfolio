About Me

I am a new up-and-coming games programmer specialising in the C++ language aswell as many engines such as Unreal, Unity and Godot. I enjoy making indie games that focus on interesting and unique gameplay mechanics that defines the game more within its respective market. I've been programming for over 5 years now and have participated in all manner of game jams to improve my abilities further. I am currently studying Games Development at Norwich University of the Arts, England.

Pyro Engine

A Specialised 2D game engine that I am currently working on. The engine uses OpenGL as it's rendering API and the platforms that will be supported upon release will be Windows & Linux. I intend in the future to use this engine to make a 2D marketed game but the current plan for it is to stay open-source so that anybody can use it. The source for it can be found here.

Galactic Pianist

Galactic Pianist is a 2D Pixel Art Rhythm game where you compete against other AI Opponents to fly a spaceship and collect coins in an infinite universe all while simultaneously trying to play the piano to keep your ship topped up with fuel. Very Interesting mechanics shown in this game but due to playtesting feedback, the game is considered to be quite difficult. The Game was submitted as course work to my university.

Orb Run

You play as an orb that has the peculiar ability to change between 2 forms: a summer and a winter form. With this ability you can change between which blocks and obstacles you will be able to see and interact with and the others that you can’t, you will be able to phase through them. Your only aim is to get to the end… It can’t be that hard, right!!! This game was submitted as course work for my university.

Bitmap Bygones

An adventure game about finding ancient artifacts within existing art pieces! Search through three retro environments within paintings mario-64 style to find three exhibits for the museum. This was submitted for Vertical Game Jam 2024 as part of a group project. Doing this really helped with my team building as well as team communication and coordination skills. The game can be found here: https://od3d.itch.io/bit-map
